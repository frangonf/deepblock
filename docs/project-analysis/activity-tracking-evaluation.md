## Inference on a 16 GB M4

- **Rules and text first.** Match known repositories, domains and window titles. For ambiguous intervals, a small 2–4B text model can classify short OCR or accessibility excerpts into a known project or leave them unresolved.
- **Vision when needed.** Qwen3.5-4B Q4 via `llama.cpp` is the cross-platform candidate. LFM3-VL-2B is a smaller candidate. Apple AFM 3 Core Advanced via `fm` is a macOS-only inference option. Published vision subsets put Apple at 79% vs Gemma 4 E4B at 77% on ScienceQA, and 48.3% vs 49.2% on MMStar. A separate quantized image test scored Qwen3.5-4B at 75.5/100 vs 73.1 for 9B. Liquid AI measured 63.5 for LFM vs 65.7 for Qwen 4B on English OCRBench v2. The studies use different test sets and do not establish a winner for project attribution. [Apple comparison](https://ndurner.substack.com/p/apple-foundation-model-3-and-siri) · [Quantized vision test](https://github.com/froggeric/llm/blob/main/benchmark/vlm/BENCHMARK-REPORT-v5.md) · [LFM results](https://huggingface.co/LiquidAI/LFM3-VL-2B)
- **Separate recording from inference.** For DeepBlock-managed inference, default to on-demand or idle-only batches, with one local job at a time and a pause under memory or thermal pressure. Check each recorder's own analysis schedule before leaving it running. Use a self-hosted or hosted endpoint by explicit opt-in, starting with selected text and keeping raw screenshots local by default. [Module contracts](../features/advanced-module-contracts.md)

## Fit with the DeepBlock roadmap

**Native macOS recording → automatic project context → intent assessment → reversible workspace assistance.** Keep the native recorder on the roadmap and use existing tools as optional evidence sources. ActivityWatch can tell us that the user was in an editor or browser. OCR and summaries can help distinguish which repository or client they were working on within the same app. [Advanced vision](advanced-deepblock-vision.md#implementation-phases-and-acceptance-criteria)

For the first retrospective trial, read a completed block's time window, suggest a project with timestamped evidence, and let the user correct it or leave it unresolved. Compare the result with ActivityWatch-only review using attribution accuracy, unresolved intervals and correction effort. Measure capture and inference overhead separately. DeepBlock owns the effective plan revision, user corrections and any later assistance decision.
