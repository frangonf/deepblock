# Project analysis

This directory separates current product guidance, implementation status, future
architecture, and historical evidence for the Rust/Tauri repository. Merged code,
platform verification, and acceptance through ordinary use are distinct statuses.

- [`mindful-self-direction.md`](mindful-self-direction.md): product purpose and experience criteria; notebook simplicity, neutral open time, voluntary reflection, and user-controlled assistance

- [`feature-gap-analysis.md`](feature-gap-analysis.md) — current Rust/Tauri gaps and their relationship to the agreed preparation and advanced roadmap

- [`pre-advanced-roadmap.md`](pre-advanced-roadmap.md) — completed planning, storage, review, and module-boundary work, recorded evidence, and ongoing validation

- [`advanced-deepblock-vision.md`](advanced-deepblock-vision.md) — future recording, automatic context enrichment, inferred assessment, and workspace assistance; manual projects/goals and intent history already exist

- [`ui-ux-audit-2026-10-01.md`](ui-ux-audit-2026-10-01.md) — historical interface findings and resolution/validation record; later identity work is documented in [Design System v1](../design-system.md)

- [`planning-baseline.md`](planning-baseline.md): dated pre-migration data and performance baseline, reusable regression checks, and revision-specific distribution evidence

Other historical records (removed Python MVP inventory, completed release-planning docs) live in [../archived/](../archived/).
