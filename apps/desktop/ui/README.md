# DeepBlock Desktop UI

React + Vite frontend for the Tauri desktop shell.

## Commands

- `pnpm run dev` — start the desktop UI dev server
- `pnpm run build` — build the production bundle consumed by Tauri
- `pnpm run lint` — lint the React source
- `pnpm run typecheck` — run TypeScript checks
- `pnpm run test:e2e` — run Playwright flows against the Rust server + desktop UI

## Scope

This UI focuses on regular clickable flows for:

- planner revisions and block management
- reality audit review
- notes editing
- backlog management
- settings updates
- revision comparison
